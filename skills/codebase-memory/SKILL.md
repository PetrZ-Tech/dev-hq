# Skill: Codebase Memory

Use as persistent technical memory for local repositories.

## Prefer it when
- Starting work on an existing codebase.
- Need architecture, relationships, prior indexed context or cross-file understanding.
- A new chat must recover project context without re-reading everything manually.

## Workflow
1. Identify the indexed project.
2. Read relevant memory/graph context.
3. Verify important paths in the live repository before edits.
4. Reindex after meaningful changes to source-of-truth files.

## HQ rule
`dev-hq` is the operational memory repository for tools, rules, environment and project registry.
