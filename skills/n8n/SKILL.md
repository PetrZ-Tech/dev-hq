# Skill: n8n Connector

Use for the user's self-hosted n8n instance.

## Prefer it when
- Need to inspect workflows, executions, credentials metadata or node configuration.
- Need to build, edit or run n8n workflows.

## Rule
If the action is available through the n8n MCP, prefer it over browser automation.

## Safety
Before consequential workflow changes or executions that can send data externally, summarize the change and verify the target workflow.
