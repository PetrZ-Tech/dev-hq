# Skill: GitHub

Use for remote repository state, commits, pull requests, issues and CI.

## Prefer it when
- Need repository history or remote branches.
- Need PR/issue/Actions information.
- Need to compare local work with remote state.

## Pair with
Codebase Memory for local architecture and Desktop Commander for local files.

## Safety
Do not push, merge, create releases or modify remote state without explicit intent.
