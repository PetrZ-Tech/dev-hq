# ADR-0002 — Границы автономности штаба

Status: `ACCEPTED`
Date: `2026-10-09`
Decision owners: `Dev HQ`

## Context
Штаб должен уметь работать автономно с кодом и проектами, но не должен без подтверждения менять Windows, сеть, production или данные вне рабочей области.

## Decision
Автономная запись разрешена только внутри `<PROJECTS_ROOT>\...` для обычной проектной работы. Изменения вне этой зоны, системные настройки Windows, сеть/VPN/DNS, службы, права, production и иные труднообратимые действия требуют подтверждения пользователя.

## Why
Так сохраняется скорость разработки без постоянных подтверждений для безопасных проектных операций и одновременно остаётся жёсткая граница для действий с большим радиусом риска.

## Alternatives considered
- Полный запрет любых записей без подтверждения — слишком медленно для ежедневной разработки.
- Полная автономия на компьютере — слишком высокий риск.
- Только server-side blockedCommands — недостаточно, поскольку техническая возможность не равна разрешению.

## Consequences
### Positive
- Быстрая автономная работа внутри проектов.
- Понятная граница ответственности для системных и production-действий.

### Negative / trade-offs
- Некоторые безопасные на вид операции всё равно потребуют подтверждения, если выходят за рабочую зону.
