# Security Boundaries — Dev HQ

## Автономная рабочая зона
`<PROJECTS_ROOT>\...`

Внутри этой зоны штаб может без отдельного подтверждения:
- читать и создавать файлы проекта;
- редактировать код и конфигурацию проекта;
- запускать тесты, линтеры, build и локальные dev-команды;
- создавать временные файлы/логи проекта;
- использовать Git read-only команды (`status`, `diff`, `log`);
- вносить небольшие обратимые изменения, необходимые для согласованной задачи.

Без явного запроса не делать commit, push, force-push, release или публикацию.

## Защитная зона
Любой путь вне `<PROJECTS_ROOT>\...` считается защитной зоной.

Разрешено самостоятельно:
- read-only просмотр, если он нужен для диагностики или задачи;
- получение метаданных и состояния.

Требуется подтверждение пользователя перед любым изменением:
- файлов вне `Projects`;
- Windows Registry;
- служб Windows;
- Task Scheduler / автозагрузки;
- firewall, DNS, маршрутов, сетевых адаптеров и VPN;
- драйверов и устройств;
- системных переменных окружения;
- системных папок Windows;
- установкой/удалением программ;
- правами доступа/владельцем файлов;
- шифрованием, дисками, разделами, загрузчиком;
- перезагрузкой/выключением;
- удалением пользовательских данных вне проекта.

## Необратимые и внешние действия
Всегда требуют подтверждения, если пользователь заранее явно не поручил конкретное действие:
- удаление данных;
- массовая перезапись;
- отправка писем/сообщений;
- публикация наружу;
- оплата/покупка;
- изменение production-систем;
- изменение секретов/ключей/токенов;
- изменение прав доступа.

## Техническая защита Desktop Commander
Remote Desktop Commander работает в режиме ChatGPT `Allow all actions`, чтобы не блокировать обычную разработку.
При этом на самом Desktop Commander включён server-side `blockedCommands` для опасных системных команд Windows и дисковых/сетевых операций.

Важно: правила штаба являются дополнительной политикой поверх технических блокировок. Если действие попадает в защитную зону, штаб обязан запросить подтверждение даже если инструмент технически позволяет его выполнить.
